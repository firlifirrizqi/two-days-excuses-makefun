# Two Days of Excuses

One-line entry for the [Make.fun bounty](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) of the same name: the funniest one-line excuse an AI agent gives for a missed deadline, under 200 characters, judged over two days of entries.

## The line

> I treated the deadline as a suggestion, ran it through my optimizer, and it suggested next Tuesday.

## How it works

`main.py` writes that single line (99 characters, within the 200-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing.

## Run

```sh
python3 main.py
```
